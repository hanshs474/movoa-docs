|---|---|---|---|---|
| `minimax-h3` (default) | text, photo | 4, 5, 6, 8, 10, 15 | 480p, 768p | 16:9, 9:16, 1:1 |
| `seedance-2-5` | text, photo | 5, 10, 15, 20, 25, 30 | 480p, 720p | 16:9, 9:16, 1:1 |

Every model returns the clip with sound. Prices per model are on [movoa.ai/pricing](https://movoa.ai/pricing); a run through the API costs the same credits as the same run on the website.
