# ComfyUI

Text to video and photo to video with sound in ComfyUI via [ComfyUI-movoa](https://github.com/hanshs474/ComfyUI-movoa).

## Install

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/hanshs474/ComfyUI-movoa.git
```

Standard library only; no extra `pip install` needed.

## Setup

Create an API key at [movoa.ai/settings/apikeys](https://movoa.ai/settings/apikeys) and set `MOVOA_API_KEY` or paste it into the node's `api_key` input.

Source: [github.com/hanshs474/ComfyUI-movoa](https://github.com/hanshs474/ComfyUI-movoa) · [Movoa](https://movoa.ai/).
